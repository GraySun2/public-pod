# Where this module came from

- **Name:** Godot touch controls (id `godot-touch-controls`).
- **Source:** the original studio's own game and template code, in private repos, written by Claude sessions under the studio owner's direction. The game-specific parts were taken out to make it general, and bugs found in review were fixed (MODULE.md lists what was tested and how).
- **Licence:** MIT, as the repo's [LICENSE](../../../LICENSE). The studio owns the source code and offers it here.

## How Claude was used

Claude sessions wrote the code for the original games, and a later session made it general, wrote the tests and the example, and had another session review it adversarially before it went into the code library.
