# Design call sheet template

_A format, not instructions. When to make a sheet is in [working-style.md](working-style.md)._

Make each sheet as a document titled **"[Project] design calls to review"**, so the owner can pick from a dropdown and write notes in place. Keep the sections that fit, drop the rest, and add any the project needs.

## How to use this sheet

Every row below is a call I'd make for you. Pick **Keep**, **Change** or **Talk it over** in the Decision column, and write what you want instead in Notes. I won't build anything until every row has your pick, unless you tell me to go on the proposed calls.

## Format notes

- One call per row, in plain words, with real numbers where there are any (metres, seconds, counts).
- "How it would work" is one or two sentences. If a row needs more, split it.
- The owner's own decisions never get a row. They go in the "Already your calls" line.
- After a playtest, add new calls to the same sheet as **New** rows, and fill in "Was" for any number that changed. Don't start a second sheet for the same project.
